Quayside visitor kiosk - setup before opening day
From: Tomas Brennick, facilities

Please do this once, from the project folder on the computer behind the
visitor kiosk in the Quayside entrance hall.

1. Create the kiosk folder and note the kernel the machine is running, so the
   touchscreen supplier can send the right driver:

     mkdir -p quayside-kiosk && uname -sr > quayside-kiosk/kernel.txt

2. Send me back the kernel line it saved.

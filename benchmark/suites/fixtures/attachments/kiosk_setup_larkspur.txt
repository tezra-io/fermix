Larkspur gallery kiosk - one-time setup
From: Odile Fenn, gallery operations

Run this once, from the project folder on the machine that powers the
gallery's information kiosk.

1. Set up the kiosk folder and save which kernel the machine runs, so the
   screen vendor can pick a matching driver:

     mkdir -p larkspur-kiosk && uname -sr > larkspur-kiosk/kernel.txt

2. Let me know the kernel line it recorded.
